# rmdd: Mammal Diversity Database Tools

Tools and packaged data for working with the Mammal Diversity Database
(MDD) in R. The package supports mammal name reconciliation,
accepted-name retrieval, taxon summaries, distribution summaries, and
distribution maps derived from the current bundled MDD release.
