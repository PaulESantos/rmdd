# Changelog

## rmdd 0.0.0.1

CRAN release: 2026-03-23

- [`mdd_distribution_map()`](https://paulesantos.github.io/rmdd/reference/mdd_distribution_map.md)
  adds customizable Natural Earth distribution maps with automatic zoom
  and exact/partial input reconciliation.
- [`mdd_distribution_summary()`](https://paulesantos.github.io/rmdd/reference/mdd_distribution_summary.md)
  adds country-, continent-, and subregion-level diversity tables with
  counts of orders, families, genera, living species, and extinct
  species.
- [`mdd_matching()`](https://paulesantos.github.io/rmdd/reference/mdd_matching.md)
  adds staged reconciliation across checklist names and synonyms using
  exact and fuzzy matching.
- [`mdd_taxon_info()`](https://paulesantos.github.io/rmdd/reference/mdd_taxon_info.md)
  returns accepted-name summaries, grouped taxonomic sections, and
  linked synonym records from packaged MDD data.
